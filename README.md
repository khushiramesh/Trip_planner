# Trip Planner

## Run locally in VS Code

1. Open this folder in VS Code.
2. Open a terminal (`` Ctrl+` `` / `` Cmd+` ``) and install dependencies:

   ```bash
   npm install
   ```

3. Start the dev server:

   ```bash
   npm run dev
   ```

4. Open the URL it prints (usually `http://localhost:5173`) — it should also open automatically.

Data is saved to your browser's `localStorage`, so it persists between reloads on the same browser/machine.
